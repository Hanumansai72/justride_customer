# JustRide Customer Experience App

A high-performance, modular React 19 + Vite application with Framer Motion animations and custom Tailwind tokens designed for JustRide motorcycle navigation.

## Features
- **Interactive Cockpit HUD Simulator**: Real-time turn arrow and route profiles.
- **Problem vs. Solution Interactive Card**: Visual comparison between smartphone mounts vs dedicated OLED HUD.
- **Hardware Bento Grid**: Highlights round display, live guidance, BLE 5.3, and IP67 weather resistance.
- **Interactive Modals**: Pre-order configurator (anodization finish, mounting clamps) and video walkthrough modal.
- **Multi-Tab Navigation**: Seamlessly switch between Home, About Us, Product Deep-Dive, Mobile App Downloads, and Contact Support.
- **100% Client-Side**: Self-contained product-level frontend.

## Quick Start
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
